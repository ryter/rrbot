# Эталоны юнитов мобильного клиента (Rush Royale, Android-эмулятор)

Набор собран `tools/collect_units_emulator.py` из настоящих кадров боя
(`assets/eval_real/frames`, 24 кадра, 483 юнита).

## Что внутри

| файл | что это |
|---|---|
| `unit_em_NN_*.png` | эталоны для детектора: квадратный вырез 81x81 px вокруг юнита (тело + кольцо основания), приведённый к каноническому масштабу (радиус основания 31 px) |
| `unit_em_NN_*_1.png`, `_2.png` | те же юниты в других кадрах анимации — детектору нужен не один повёрнутый силуэт |
| `sprite/unit_em_NN_*.png` | тело юнита без основания (силуэт по чёрной обводке) — для других способов сопоставления |
| `index.tsv` | манифест: файл, размер, сколько встреч, цвет тела и основания, примеры позиций |
| `types.tsv` | соответствие «карточка в колоде → спрайт эталона» (проверено по боевым кадрам) |
| `preview/` | карточки колоды рядом с эталонами и настоящие юниты каждого типа |

## Почему в эталоне основание

Совпадение одного и того же типа юнита между двумя кадрами:

| что в эталоне | NCC между двумя кадрами | доля юнитов с совпадением ≥ 0.6 |
|---|---|---|
| вырез с основанием (эти эталоны) | 0.65-0.75 | ~100 % |
| только тело юнита (силуэт) | 0.20-0.42 | ~20 % |

У тёмных юнитов силуэт почти без контраста, и нормализованная корреляция
по нему нестабильна. Кольцо основания — яркая метка, по ней юнит находится
надёжно; цвет основания у своего и чужого юнита разный, но в эталон он
попадает вместе с телом, и для одного типа он одинаков.

## Как пересобрать

```bash
.venv/bin/python tools/collect_units_emulator.py \
    --frames assets/eval_real/frames --truth assets/eval_real/truth.tsv \
    --out assets/real_emulator --types-count 8 --variants 3
```

`--types-count` — на сколько типов делить найденных юнитов (k-means по
цвету выреза и форме силуэта), `--variants` — сколько кадров анимации
хранить на тип. Сбор детерминирован: повторный запуск даёт те же файлы.

## Как замерить

```bash
# эталоны веб-клиента (было)
.venv/bin/python tools/evaluate_vision_cpp.py --mode real

# эталоны мобильного клиента (стало)
.venv/bin/python tools/evaluate_vision_cpp.py --mode real \
    --templates assets/real_emulator --map <имя>=<файл>,... --types <имена> \
    --threshold 0.50 --max-per-template 12
```

На 24 кадрах (483 юнита):

| порог | веб-клиент: recall / precision | мобильный: recall / precision |
|---|---|---|
| 0.45 | 0.702 / 0.083 | 0.636 / 0.498 |
| 0.50 | 0.640 / 0.091 | **0.592 / 0.531** |
| 0.55 | 0.580 / 0.106 | 0.528 / **0.576** |
| 0.60 | 0.389 / 0.129 | 0.437 / 0.549 |

Ошибка позиции: 12-13 px → 9 px.
