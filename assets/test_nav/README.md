# Набор кадров для проверки навигации

Записанные экраны игры и ожидаемое действие бота на каждом из них.
Инструмент `tools/check_nav.py` гоняет по кадрам настоящий бот
(`cpp/build/rrbot --backend adb --frame <кадр>`) и сверяет его кандидаты
навигации с `labels.txt`.

```bash
.venv/bin/python tools/check_nav.py            # отчёт
.venv/bin/python tools/check_nav.py --verbose  # отчёт по каждому кадру
.venv/bin/python -m pytest tests/test_cpp_nav.py
```

## Файлы

* `*.png` — кадры экранов, все ровно 950x1034 (система координат
  мобильного клиента, см. `cpp/src/layout.cpp`). Это ровно тот размер,
  в котором бот видит экран: `Hud` приводит кадр к холсту через
  `cv::resize(..., INTER_AREA)`.
* `labels.txt` — разметка.

## Формат `labels.txt`

Каждая строка — ровно 9 полей:

```
имя_кадра.png вид x y w h запреты бой обязательные
```

* **вид** — что бот должен нажать **первым**:
  `pvp`, `coop`, `close`, `cancel`, `ok`, `continue` или `none`
  (на этом экране жать нечего: допустим только безопасный `tap` в центр).
* **x y w h** — прямоугольник нужного элемента в координатах холста
  950x1034. Точка нажатия бота должна попасть внутрь него.
* **запреты** — через `;` то, чего в кандидатах быть не должно:
  * `вид` — такого вида кандидата быть не должно вовсе;
  * `вид@x,y,w,h` — кандидат такого вида не должен указывать в этот прямоугольник;
  * `@x,y,w,h` — ни один кандидат не должен указывать в этот прямоугольник
    (например, кнопку покупки: её жать нельзя никогда).
* **бой** — `да`, если на кадре идёт бой (проверяется `Hud::in_battle`),
  иначе `нет`.
* **обязательные** — через `;` виды, которые бот обязан предложить
  **кроме первого** (например, кнопка `Co-Op` рядом с `PvP`).

Знак `-` означает «требований нет».

## Какие экраны покрыты

| префикс | экран |
|---|---|
| `menu_pvp_*` | главное меню: оранжевая кнопка «PvP», синяя «Co-Op» |
| `matchmaking_*` | подбор соперника: баннер «PvP» и кнопка «Отмена» |
| `offer_*` | окно предложения: крестик, бейдж «-80%», кнопка покупки «6,30 €» |
| `chest_*` | окно сундука «Стучатся победы!»: крестик, «Продолжить», «Смотреть» |
| `gold_dialog_*` | окно «Золото»: крестик и кнопка «Понятно» |
| `hero_screen` | экран героя «Капитан»: крестик и полоса иконок меню |
| `battle_*` | бой: HUD с энергией и виджетом призыва |
| `result_*` | итоги боя: лента «Победа»/«Поражение» и кнопка «Продолжить» |
| `reward_panel_*` | экран награды: оранжевая «Заработать» и «Продолжить» |
| `loading` | загрузка |

## Откуда кадры

Записаны вручную с эмулятора (`adb exec-out screencap -p`) в прогонах
меню и боя: `/tmp/opencode/frames2` (700 кадров), `/tmp/opencode/frames3`
(400 кадров) и одиночные снимки в `/tmp/opencode/*.png`. Кадры приведены к
размеру холста 950x1034 и сжаты без потери точности (PNG, уровень 9).
