# Разметка набора кадров для проверки навигации бота.
#
# Формат строки (ровно 9 полей):
#     имя_кадра.png вид x y w h запреты бой обязательные
#
# вид — что бот должен нажать ПЕРВЫМ на этом экране:
#     pvp       — кнопка «PvP» главного меню
#     coop      — кнопка «Co-Op» главного меню
#     close     — красный крестик закрытия окна
#     cancel    — кнопка «Отмена» на экране подбора соперника
#     ok        — синяя кнопка внутри окна («Понятно», «Продолжить»)
#     continue  — нижняя кнопка «Продолжить» на экране итогов
#     none      — жать нечего: в списке кандидатов допустим только
#                 безопасный «tap» в центр экрана
#
# x y w h — прямоугольник элемента в координатах холста 950x1034
#     (та же система координат, что и у кадров в этом каталоге).
#     Точка нажатия бота должна попасть ВНУТРЬ этого прямоугольника.
#
# запреты — через «;» то, чего в списке кандидатов быть не должно:
#     вид            — такого вида кандидата быть не должно вовсе;
#     вид@x,y,w,h    — кандидат такого вида не должен указывать в этот
#                      прямоугольник;
#     @x,y,w,h       — ни один кандидат не должен указывать в этот
#                      прямоугольник (например, кнопку покупки).
#     «-» — запретов нет.
#
# бой — «да», если на кадре идёт бой (проверяется тем же способом, как
#     в cpp/src/hud.cpp: Hud::in_battle), иначе «нет».
#
# обязательные — через «;» виды, которые бот ОБЯЗАН предложить (кроме
#     первого): например, кнопка «Co-Op» рядом с «PvP» или синяя
#     «Понятно» внутри окна. «-» — таких требований нет.
#
# Кадры: 950x1034, мобильный клиент (эмулятор). Разметка сделана по
# смыслу экрана, а не по текущему поведению бота.
